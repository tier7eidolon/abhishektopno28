## 💭 Engineering Philosophy

I believe strong engineering is built on **solid fundamentals**.

Rather than chasing every new **technology** or **framework**, I focus on understanding the principles behind **algorithms**, **computer systems**, **software design**, and **performance engineering**.

My goal isn't just to write code that works, but to build software that is **correct**, **efficient**, **maintainable**, and **well engineered**.

Whenever possible, I prefer implementing concepts **from scratch** before relying on libraries because understanding **why** something works is just as important as making it work.
